# miRNA Database and SQL Explorer
Developed a **unified miRNA database** and accompanying live **SQL querying app** with a contextual schema browser, integrating data from **11 public repositories** and **25 datasets**. Raw data ingestion was followed by identifier normalisation, ontology-based mapping, and duplicate removal, with disease annotations generated via NCBO Annotator using MeSH ontologies and miRNA identifiers harmonised through custom miRBase scripts. The pipeline achieved a **96% annotation success rate** and an **87% ontology mapping rate**. The backend schema captures **over 109k miRNA–disease associations**, encompassing **>4,500 miRNAs**, **~2,200 diseases**, and **10+ relationship types** (miRNA–target, miRNA–lncRNA, SNP–disease, epigenetic links, drug response, and more), enabling multifaceted biomedical analyses.
